Inter variable WOFF2 subsets, normal style, sourced without modification from
`@fontsource-variable/inter` 5.3.0 on npm (Inter Project, SIL OFL 1.1).
The original license is shipped at `/licenses/Inter-OFL.txt`.

`inter.css` retains the original Unicode ranges, uses the existing `Inter`
family name and 400–800 weight range, and uses `font-display: swap`.
Browsers request only subsets used on the page. Vite fingerprints the font files;
Pages and Caddy can cache them like other versioned assets. No npm runtime
dependency or Google Fonts request is required.

Upstream: https://github.com/rsms/inter
